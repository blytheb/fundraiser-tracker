# Fundraiser Tracker Requirements

## Purpose

Replace Google Sheets used for tacking team fundrasing and player travel accounts.

## Problem

Currently:

- Fundraiser money is tracked manually
- Player balance require copying spreadsheets
- Parents canot easily view their child's account
- Admin must manually calculate balances

## Goal

Create a systme that allows admins to:

- Manage seasons
- Track players
- Track Fundraising
- Track player account balances
- View financial history

## Users

### Admin

Can:

- Create seasons
- Add Players
- Create fundraisers
- Enter payments
- View All accounts

### Parents (Future)

Can:

- Login
- View their player's account
- View balance history
